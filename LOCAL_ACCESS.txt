BD Home Hunt - How to get a real phone link

=== THE KEY INSIGHT ===
Supabase = your live backend (database + realtime sync)
The dashboard itself (index.html + manifest) is a static website.
Static websites need to be hosted somewhere (Netlify, GitHub Pages, Vercel, etc.)
You can't just "open it from Supabase".

=== FASTEST WAY TO A PHONE LINK (30 seconds) ===
1. Go to https://app.netlify.com/drop in your browser
2. Drag the entire "home-hunt-supabase" folder from Finder onto the drop zone
3. Wait a few seconds
4. Copy the URL it gives you (something like https://cool-unicorn-123.netlify.app)
5. Open that URL on your iPhone
6. (Recommended) Share button → "Add to Home Screen"

This gives you a real public link that works from anywhere.
The Supabase realtime still works perfectly.

You can re-drag the folder anytime to update.

=== AFTER YOU HAVE THE LINK ===
- Open on phone → Add to Home Screen for app-like experience
- Share the same link with your partner
- Both of you can add/edit/rate properties and see changes live

The local server stuff is no longer needed (and was causing the firewall popups).

=== FOR THE "ANALYZE URL" FEATURE (paste realtor.ca link directly) ===
After deploying:

1. In your Netlify dashboard → Site settings → Environment variables
2. Add a variable:
   Key: XAI_API_KEY
   Value: your xAI Grok API key (get from https://console.x.ai/ )

   (Optional) Key: GROK_MODEL
   Value: grok-3   (or grok-2-latest etc. if you have access to a specific one)
3. Redeploy (or it will pick it up on next deploy)

Then in the app, the "paste a realtor.ca URL" option will call Grok automatically in the background using your key (server-side, key never exposed to browser).
