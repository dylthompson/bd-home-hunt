=== BD Home Hunt - Phone Access ===

The proper way is to host on Netlify connected to GitHub (for a permanent public link).

See the file GITHUB_SETUP.md in this folder for the complete beginner step-by-step (create GitHub repo → push → connect to Netlify).

Quick version:
1. Create empty repo at https://github.com/new (do NOT initialize with README)
2. In this folder run the three commands GitHub shows you (git remote add..., git push...)
3. In Netlify: Add new site → Import from Git → select your repo
4. Set Base/Build/Publish settings as described in GITHUB_SETUP.md
5. Add XAI_API_KEY in Environment variables (very important for the "Analyze URL" feature)
6. Use the public netlify.app URL on your phone + "Add to Home Screen"

The local server has been stopped.
